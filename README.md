# Battery Runtime Calculator
A Java object-oriented programming project that calculates the estimated runtime of a battery-powered device, the number of batteries required for different operating times, and the associated battery costs.

## Features
- Calculates estimated battery runtime
- Uses an 85% battery safety factor
- Calculates batteries required for 8, 16, and 24 hours of operation
- Calculates total battery cost
- Calculates remaining budget
- Accepts user input through the console
- Uses Java OOP concepts including classes, constructors, encapsulation, getters, setters, and methods

## Technologies
- Java
- IntelliJ IDEA
- Object-Oriented Programming
